# VCET Vazhi Kaati 
- Web based navigator for the Velalar College of Engineering and Technology Campus .

---

## To Contribute to the project

### Backend 
- The Api responsible for shortest path finding and coordinate mapping is in 
```
> cd backend
```

### Frontend 
- The maps that is shown in the frontend is in, 
```
> cd frontend
```

## To run the project 
```
> node server.js
(or)
> make node_run 
```
- For a comprehensive styling manual (editing colors, nodes, edges, corridors, rooms, and animations), refer to [SVG CSS Styling Guide](SVG_CSS_STYLING_GUIDE.md).
